# Pi Finder
A Python GUI that searches the digits of pi for hidden patterns.

## Run it (no coding needed)
1. Install Python from python.org (tick "Add Python to PATH" in the installer)
2. On this page, click Code > Download ZIP, then unzip it
3. Open the unzipped folder, type `cmd` in the folder's address bar, press Enter
4. Run: python pi_finder.py
5. Wait a few seconds for the digits to load, then search!
